## Main Learning

Fine-tuning is a fundamental GenAI skill.

It is not only about training a model. It is about adapting a pretrained model for:

- A specific domain
- A specific task
- A specific tone
- A specific business workflow
- A specific output format
- A specific safety requirement

---

## Important System Flow

A real-world GenAI system may follow this pattern:

```text
Pretrained Model
        ↓
Fine-Tuned Model
        ↓
RAG System

Agent Workflow

Evaluation

        ↓
Deployment
